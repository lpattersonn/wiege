## Changes made by the design-system critic (these supersede entries above)
- Icons in `@/components/glyphs/icons` now wrap lucide-react (same component names and props).
- `QuizOption` is a `role="radio"` with a `checked` prop; `disabled` is exposed as `aria-disabled` so focus stays put. Use the new `QuizChoices` radiogroup (roving tabindex, arrow keys, Home/End) to hold the options.
- `Segmented` is a real radiogroup.
- `TapWord` has a `preOpen` prop (desktop ≥1024px opens 500 ms after fonts are ready; any user interaction cancels it). The landing hero uses it via `HeroTapDemo`.
- `Flashcard` word auto-fits via the `--flash-fit` container calc; don't override its font size.
- `readingPrefsAttributes()` and freshness helpers are importable from server code (moved out of 'use client' files) — check the source for their current module paths.
- When in doubt, read the component source: it is the truth; this list is a map.
